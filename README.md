# 📚 Library Management System

A simple console-based Library Management System built in Java to revise Core Java concepts such as OOP, ArrayList, packages, methods, constructors, encapsulation, and basic application design.

---

## 🚀 Features

- ✅ Add Book
- ✅ Display Books
- ✅ Search Book
- ✅ Borrow Book
- ✅ Return Book
- ✅ Remove Book
- ✅ Library Statistics

---

## 🛠️ Technologies Used

- Java
- VS Code
- ArrayList
- Object-Oriented Programming (OOP)

## 🎯 Purpose

This project was built as a Core Java revision project after completing the Telusko Core Java course. The goal was to apply the concepts learned by building a complete CRUD-style console application before moving on to DSA and Spring Boot.
